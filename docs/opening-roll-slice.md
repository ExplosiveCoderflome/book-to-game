# 开局随机人物数值（Opening Roll）· 精简策划案
状态：策划草案（2026-11-05） · 未交 UI · 不 commit

## 1. 目标与爽点
- 每局开局都不同：同一个世界，因为根骨、出身不同，前 30 分钟的玩法路线就不一样（G8 开局方向数）。
- 爽点有三个：
  - 抽到好数值的惊喜（「天灵根！」）。
  - 抽到坏数值后逆天改命的反差（「废柴开局」）。
  - 掷骰前能看到这次可能抽到什么，抽完后结果带有画面感，用一句判词收束。
- 原则：随机只决定起点，不决定结局。任何开局都必须能走到至少 2 个非失败结局。

## 2. 作者可配置参数（积木 `openingRoll`，挂在数值模板上）
| 参数 | 说明 | 默认 |
|---|---|---|
| `enabled` | 是否启用 | false（旧世界不受影响） |
| `mode` | `perStat` 每项独立掷 / `pointBuy` 总点数随机分配 / `preset` 从作者写好的若干套里抽 | perStat |
| `stats[]` | 每项：`resourceId`、`min`、`max`、`dist`（`uniform` / `bell` / `skewLow` / `skewHigh`）、`step` | dist=bell，step=1 |
| `pointBuy.total` | 总点数，可以写成一个区间 | — |
| `pointBuy.perStatMin` / `perStatMax` | 单项下限和上限 | 取对应资源的 min 和 max |
| `presets[]` | `{id, weight, values, tags}` | — |
| `rerolls` | 重掷次数（0 表示不能重掷） | 2 |
| `choice` | `single`：掷一次接受 / `pickOf`：一次出 N 套选 1 | single |
| `pickOf.n` | 一次出几套 | 3 |
| `keepBest` | 重掷后能否回到之前掷过的某一套 | true |
| `floor` | 保底规则：总评分 ≥ X，或至少一项 ≥ Y；不满足就自动重掷，不消耗次数 | 总评分 ≥ 区间的 25% 分位 |
| `score` | 总评分的计算方式：各项带权重相加 | 等权 |
| `tiers[]` | 按评分分档：`{id, minScore, label, verdict}`，verdict 是一句判词 | 3 档 |
| `tags[]` | 标签规则，见 §4 | [] |
| `seedPolicy` | `run`：用这一局的种子 / `fixed`：作者固定一个种子，供测试用 | run |
| `lockAfterStart` | 开局后数值是否锁定，不能再重掷 | true |

## 3. 玩家侧流程
1. 新开一局，进入「投胎」页。页面显示世界简介、每项属性的范围条，以及剩余重掷次数。
2. 点「掷」：动画控制在 1 秒内，出数值、档位标签、判词和触发的标签。pickOf 模式同时出 N 张卡。
3. 可以重掷，按钮上直接写「重掷（剩 2）」。keepBest=true 时，掷过的每一套都列成小卡，随时能切回去。
4. 点「就这样」：数值和标签写进初始状态，开局事件入队，进入正文。
5. 存档记录种子、掷骰次序和最终选中的那一套，读档不重掷。
- 手机端：一屏放下，按钮 ≥44px，pickOf 的卡片竖排。
- 跳过：作者可以提供一套「标准开局」，玩家选了就不随机。

## 4. 与出身、天赋、事件的联动
- 标签规则 `tags[]`：`{id, when: Condition, grant: {facts[], resources{}, storylets[], events[]}, label, exclusive?}`
  - `when` 沿用现有条件写法（atLeast、atMost、range、anyOf），条件对象是掷出来的数值。
  - 例子：根骨 ≥9 → 天灵根；悟性 ≤2 且心性 ≥8 → 「愚而坚」。
- 出身 `origin`：可以随机（按权重，或受数值影响），也可以由标签决定。出身写入一个 fact，并替换开局场景的 textVariant。
- 开局事件：标签可以塞一张紧急剧情卡（urgent storylet），在第 1–3 个月必定出现，负责把标签兑现成剧情，避免只在数值上加个成。
- 互斥：同组标签用 `exclusive: "<组名>"` 标明，按数组顺序取第一个成立的。
- 补偿规则（推荐）：极端低值自动获得一个补偿标签，比如「废灵根 → 体修门路」，让坏开局有一条专属路线。

## 5. 平衡与防坏档
- 保底：用 floor 避免完全没法玩的开局。lint 检查最差情况：把各项都取 min 时，至少有 2 个非失败结局可达（由模拟器验证）。
- 封顶：开局值不能超过对应资源 max 的 70%，留出成长空间（lint 给警告）。
- 模拟测试：playtest 增加两种开局策略，`rollRandom` 和 `rollWorst`/`rollBest`。报告中写明每个档位的结局分布，以及每个标签的出现率和兑现率（对应的开局卡确实出现过）。
- 门槛：worst 档的失败结局率 ≤60%；任一档位最常见的结局 ≤50%；每个标签的出现率 ≥1%，除非作者把它标为 `rare`。
- 复现：同种子、同掷骰次序，结果逐字一致（并入 G5）。重掷只消耗 RNG，不能用读档刷：掷骰次序写进存档，读档后继续同一序列。
- 旧档：没有 openingRoll 的世界行为不变。新增字段走契约扩展（K16），玩家端不显示未触发的标签（防剧透）。
- 包体：只加积木和一个页面，预计 <10KB。

## 6. 示例配置
### 6.1 修仙《寿灯》：perStat + 天赋
- 根骨 1–10（bell），悟性 1–10（bell），心性 1–10（skewHigh），寿元 35–45（uniform，step 1）。
- 重掷 2 次，single 模式，keepBest。
- 档位：凡骨 / 中人 / 奇才，判词如「三灵根，平平无奇，灯油四十年」。
- 标签：
  - 根骨 ≥9 → 天灵根（修为速率 +30%；开局卡：长老侧目）。
  - 根骨 ≤2 → 废灵根（解锁体修线；开局卡：杂役院的老头）。
  - 寿元 ≤36 → 短命相（照晚提前出现）。
- 平衡：天灵根不能直通结丹，因为心魔上限不变。

### 6.2 经营《万宝楼》：pointBuy + 出身三选一
- 总点数 18–24，分到口才、眼力、本钱、人脉四项，每项 1–8。
- pickOf 3，不能重掷。
- 出身按本钱决定：本钱 ≥6 → 富商之子（开局灵石 ×3，但带一笔欠债事件）；人脉 ≥6 → 牙行学徒（开局解锁两家货源）；其余 → 流民（开局卡：第一笔生意）。
- 标签：眼力 ≥7 → 识宝（鉴定类选项必定成功）。

### 6.3 战斗《镖局》：preset + 少量随机
- 6 套预设（刀客、弓手、拳师、书生、医女、乞儿），按权重抽。
- 每套预设在力、敏、体、智上各 ±1 浮动；重掷 1 次。
- 标签：体 ≤2 → 旧伤（每 12 个月有一次复发事件，可以被医女线治好）；智 ≥8 → 军师（解锁布阵选项）。
- 平衡：每套预设在模拟中都要能走到「押镖成名」结局，且比例 ≥15%。
