# Agent 工作区页面改版 · 2026-10-29

## 界面与流程

作者端从编号顶部流程页改为常驻侧栏：Agent、原作、制作任务、世界草稿直接可见，辅助编辑工具收在创作工具中，会话历史与导航共用一条侧栏。Agent是默认入口；各作者页面可通过hash直接打开，前进/返回可恢复页面。玩家壳独立保留。

中间是对话与常驻输入区。空白状态提供具体创作入口，输入区显示所选草稿和配置模型。草稿ID/版本作为显式上下文随消息发送，不把全文自动附入。长消息、标题、列表、代码和强调以安全React文本呈现，不执行模型HTML。工具回执先显示可读摘要，具体JSON按需展开；仅工具调用的内部轮次不重复堆头像和消息框。

右侧作品面板来自本机实际数据：草稿标题与版本、地点/剧情卡/结局数量、玩家身份、关联制作进度、发布状态和原作入口。另一页显示当前会话的真实执行记录。操作确认卡放在对应提议旁，展示目标和前后差异、精确参数及确认/拒绝；失败、未执行、部分读取、拒绝与结果未确认各自区分。

手机不把桌面侧栏堆到聊天上方：导航、会话和上下文使用原生dialog，支持焦点管理与Escape。输入区保持可见，正文区域独立滚动。对话未配置模型、加载、请求失败、执行中和本地服务断开状态均提供明确反馈。

视觉概念、tokens、参考来源和审查修复记录见根目录 `DESIGN_SYSTEM.md`。保留绿色品牌和原生字体，不增加UI包或图片依赖。主创作页面与导航已重做；地图、分支图、资产等专业编辑器保留原有内容编辑能力，本轮没有逐个重画这些编辑器内部。

- 英文1280×720检查通过，随后恢复中文。移动端上下文→对应草稿→浏览器返回、导航与会话抽屉均检查。
- 复用当前DeepSeek配置实际执行只读对话：读取草稿摘要、关联制作任务和已有体检报告；工具摘要与执行记录正常出现。没有生成新游戏或读原作/正文全文。
- 实际提议一次标题修改，检查确认卡及差异后拒绝。随后通过业务API确认：草稿仍是v4，标题仍为「武林外传：同福旧账」；测试操作为rejected，无pending操作，没有发布或创建制作任务。
- 模型首次把“准备确认卡”误解为需要先口头征求同意，已明确工具提议与作者最终执行的区别；不增加第二道口头批准。
- 界面审查修正了旧shell外边距、空会话错误自动滚动、工具details继承大间距、手机标题孤字、无名图标按钮、上下文ID混入会话标题、抽屉跳转后未主动关闭等问题。
- 主要配色对比度已计算：次级文字对白5.67:1、对侧栏5.08:1、对浅绿4.79:1，按钮白字对绿6.29:1。未测量或宣称真实Core Web Vitals达标。
