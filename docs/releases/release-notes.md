# 发布记录

### 2026-10-11

#### 新增

- 模型设置提供 OpenAI、DeepSeek、阿里云百炼、硅基流动、Kimi、OpenRouter、Mistral、Ollama 和 LM Studio 等常用服务商预置，可获取实时模型列表并选择模型。
- 分支故事支持数值、字符串和布尔变量，以及选项条件、赋值和数值增减效果；试玩会保存变量状态并支持幂等重试。
- API 和 worker 写入按组件、日期分割的结构化 JSONL 日志，HTTP 响应携带请求 ID，便于从页面错误定位到服务端记录。
- 浏览器工作台增加无需访问码的本机演示路径，保留 MCP 的访问码保护，并提供无需模型即可试玩的示例。

#### 优化

- 模型服务配置保留手动地址和模型输入；预置只填写 OpenAI 兼容地址，不覆盖 API Key，切换服务来源时要求重新填写或明确清除旧密钥。
- 工作台支持中文与 English 切换，统一改进原作导入、生成、草稿编辑、世界预览和试玩页面的状态提示与错误展示。
- 已保存的模型配置、任务恢复、SQLite 事务和发布版本继续使用原有数据格式，重启后可恢复。

#### 修复

- 修复模型列表和连接测试的错误提示、请求鉴权和密钥回显边界。
- 修复变量条件下的选项展示、动作重试和发布校验问题。
