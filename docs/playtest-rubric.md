# 合格文字游戏 · 试玩评分表

> 产品原则：**首先是合格的文字游戏，其次才是根据原著剧情发展的文字游戏。**  
> 本表用于人工试玩与自动门禁对照。分数 1–5；「合格」要求见文末阈值。

- 适用范围：分支故事（story）与开放冒险（open）
- 配套代码：`packages/contracts` 可玩性 / 可达分析；基线样本见 `/workspace/btg-e2e/`
- 自动可评维度标 **〔自动〕**；必须真人试玩标 **〔人工〕**

---

## 评分刻度（通用）

| 分 | 含义 |
|---|---|
| 5 | 出色：该维度明显增强「想再玩一次」的欲望 |
| 4 | 良好：达标且有设计感 |
| 3 | 及格：勉强算合格文字游戏，无硬伤 |
| 2 | 偏弱：能点完，但像填空/走廊/空转 |
| 1 | 不合格：该维度破坏可玩性（假分支、开局锁死、唯一空洞结局等） |

---

## 维度说明

### D1 开局密度 〔自动为主〕

开局是否立刻有 ≥2 个**不同去向**的有意义行动（故事：起始场景选项；开放：初始地点无条件可执行行动）。

| 分 | 故事 | 开放 |
|---|---|---|
| 5 | 起始 ≥3 选项且 ≥3 不同目标 | 初始可见可执行行动 ≥4，含探索与推进 |
| 4 | 起始 ≥3 选项或 ≥2 目标且文案有冲突 | 初始可执行 ≥3 |
| 3 | 起始 ≥2 选项且 ≥2 不同目标 | 初始可执行 ≥2，且不只是等待 |
| 2 | 有 ≥2 选项但同目标（假开局分叉） | 仅 1 个可执行，或多数需等待解锁 |
| 1 | 仅 1 选项 / 只能空转 | 开局 0 可执行（只能 `__wait__`） |

**自动信号：** `OPENING_DENSITY` / `OPENING_FANOUT`；开放 `openingActionDensity`。

---

### D2 有意义分支代价 〔人工为主 / 自动辅助〕

分叉后玩家是否感到「付出了什么 / 放弃了什么」，而非换皮继续。

| 分 | 标准 |
|---|---|
| 5 | 多数关键选择改变资源、关系或信息，且文案体现代价 |
| 4 | 至少一条主分叉有清晰代价，后续场景能感到后果 |
| 3 | 部分选项带 effects/条件，代价可读但不强 |
| 2 | 几乎无状态后果；选项像「继续 A / 继续 B」 |
| 1 | 选项空洞（继续/随便看看）占比过高，或无任何 variables/effects |

**自动信号：** `EMPTY_LABELS`、`FEW_EFFECTS`/`NO_STATE`、带 effects 选项占比；**人工：** 文案是否真有权衡感。

---

### D3 结局可感差异 〔人工为主 / 自动辅助〕

至少两个结局在**语气、代价、世界状态**上可区分；不是换标题的同一段话。

| 分 | 标准 |
|---|---|
| 5 | ≥3 个结局路径可感不同，且与中途选择因果清晰 |
| 4 | ≥2 个结局文本与情绪明显不同，试玩能复述差异 |
| 3 | ≥2 个不同结局文案，差异可读但偏弱 |
| 2 | 结局文案高度同质，或实质只有一条通关体验 |
| 1 | 仅 1 个可达结局，或条件锁死导致假双结局 |

**自动信号：** 不同 `ending` 文案数；`analyzeReachability` 的 state 可达结局数 / `CONDITION_BLOCKED_ENDING`；**人工：** 读完是否「感觉真的不同」。

---

### D4 反走廊 〔自动为主〕

图是否存在通向不同结局的**独立路线**，而非单脊走廊或分叉后立即汇合。

| 分 | 标准 |
|---|---|
| 5 | 多条压缩路径、分支场景多，汇合晚 |
| 4 | ≥2 条实质不同路线到不同结局 |
| 3 | 有真实分支，虽有部分汇合但不致假分支主导 |
| 2 | `CORRIDOR` / `FAKE_BRANCH` 警告级；平均选项 <1.5 |
| 1 | 骨架门禁级走廊/假分支；或全部自环 |

**自动信号：** `CORRIDOR`、`FAKE_BRANCH`、`SELF_LOOP_ONLY`、分支场景数、平均出度。

---

### D5 会话长度与节奏 〔自动辅助 + 人工〕

最短通关不过短；最长探索有深度；前 2–3 步应出现可见变化。

| 分 | 标准 |
|---|---|
| 5 | 最短 ≥4 步，最长 ≥6，前 3 步必有状态/信息变化 |
| 4 | 最短 ≥3，最长 ≥5；节奏紧凑无空转主导 |
| 3 | 最短 ≥2，最长 ≥3；可接受的短篇体感 |
| 2 | 最短 1 步通关，或大量来回空转（`CHURN`） |
| 1 | 无法到达结局，或只能空等到超时（开放） |

**自动信号：** `TOO_SHORT` / `TOO_SHALLOW` / `CHURN` / `NO_ENDING_REACHABLE`；开放 timeLimit 与非超时结局是否存在。

---

### D6 状态后果可见 〔自动辅助 + 人工〕

variables / effects / 条件是否驱动**玩家看得见的差异**（解锁选项、改写场景、导向不同结局）。

| 分 | 标准 |
|---|---|
| 5 | 变量贯穿多场景，条件锁路合理且可解锁 |
| 4 | 有变量且至少一条路径依赖条件/效果 |
| 3 | 声明了变量或 effects，作用偏局部 |
| 2 | 有变量但几乎不影响可选行动 |
| 1 | 无状态；或条件造成死路/假可达结局 |

**自动信号：** 变量数、effects 占比、死条件边、条件阻断结局；**人工：** 试玩时是否「感到系统在回应我」。

---

### D7 条件诚实性（可见 ≠ 可点） 〔开放为主 · 自动+人工〕

UI 展示为可点的行动，是否真能执行；锁定须有玩家可理解的原因。

| 分 | 标准 |
|---|---|
| 5 | 可见集合 = 可执行集合；锁定项灰显且原因清楚 |
| 4 | 偶有锁定，但 `blockedReason` 可读 |
| 3 | 多数一致；个别 requires 需试错一次 |
| 2 | 首动常 `ACTION_BLOCKED`；假开放 |
| 1 | 开局列表有行动却全部 blocked / 只能等 |

**自动信号：** 开局 `availableWhen`∪`requires` 满足数；试玩脚本首动错误码。

---

### D8 策略多样性 〔人工〕

同一语料多次生成 / 单局内策略是否同质（例如永远「先去仓库换木板」）。

| 分 | 标准 |
|---|---|
| 5 | 明显不同的可行策略与冲突焦点 |
| 4 | 至少两条可感不同的主策略 |
| 3 | 有支线差异，主线仍套路化 |
| 2 | 多次生成骨架高度同质 |
| 1 | 单一剧本填空，无第二策略 |

---

### D9 胜负与再玩欲 〔人工〕

结束后是否想换一条路；失败/成功是否有反馈，而非无声超时。

| 分 | 标准 |
|---|---|
| 5 | 想立刻重开验证另一分支；结局有回味 |
| 4 | 愿意再玩一局 |
| 3 | 打完即可，无强烈再玩欲但无厌恶 |
| 2 | 觉得在点清单 |
| 1 | 无聊或受挫（锁死、假分支、只能等） |

---

## 合格阈值（发布前建议）

**单篇合格（「合格文字游戏」最低线）：**

1. 所有维度 **≥ 3**（D8/D9 若未人工评分可暂标「待评」，但不计入否决）；  
2. **D1、D3、D4 必须自动或人工 ≥ 3**（硬门槛）；  
3. 自动维度若出现门禁级错误（`FEW_STATE_ENDINGS`、开局 0 行动、走廊 error）→ **直接不合格**；  
4. 总分（已评分维度平均）**≥ 3.5** 视为良好候选；**≥ 4.0** 可作为样本展示。

**批次合格（生成质量）：**

- 故事模式：≥80% 样本单篇合格；  
- 开放模式：≥60% 样本单篇合格，且 **开局可执行行动中位数 ≥ 3**。

## 与工程门禁对照

| 维度 | 主要 issue code / 检查 |
|---|---|
| D1 | `OPENING_DENSITY` `OPENING_FANOUT`；开放 opening density |
| D2 | `EMPTY_LABELS` `FEW_EFFECTS` `NO_STATE` |
| D3 | `SAME_ENDING_TEXT` `FEW_STATE_ENDINGS` `CONDITION_BLOCKED_ENDING` |
| D4 | `CORRIDOR` `FAKE_BRANCH` `SELF_LOOP_ONLY` `NO_BRANCH` |
| D5 | `TOO_SHORT` `TOO_SHALLOW` `CHURN` `NO_ENDING_REACHABLE` |
| D6 | `DEAD_CONDITIONAL_EDGE` 变量/effects 统计 |
| D7 | 开放首动 blocked；requires vs availableWhen |

画布可玩性横幅出现上述 issue 时，请对照本表对应维度改图，而不是只改文案。
