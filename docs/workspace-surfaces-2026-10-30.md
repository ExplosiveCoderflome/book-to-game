# 作者操作界面统一 · 2026-10-30

本轮在现有 Agent 对话工作台上完善所有九个作者操作页：原作书架、制作任务、世界编辑、分支编辑、建筑库、物品目录、开放冒险试玩、分支试玩、模型设置。保留独立玩家阅读界面和原有数据/生成/发布协议。

## 操作变化

- 各页共享标题、说明、操作区与 Agent 讨论入口；侧栏补充真实最近作品。统一表面、字号、输入控件、通知、空态和工具栏；沿用绿色主题、自绘线性图标与系统字体。
- 全局搜索（Ctrl/Cmd+K）搜索页面、原作、草稿和任务，支持多词匹配、键盘选择、Escape 关闭；任务搜索直接清除冲突过滤并定位相应记录。
- 书架先展示资料列表及搜索，导入与内置示例按需展开，原文保持阅读行宽。制作页先展示真实任务总数、进度、状态/关键词过滤和审阅入口，新简报表单可展开。
- 世界与分支编辑器收拢高级操作为“更多工具”，保留模式和视图选择；手机检视器纵向排列，体检报告在窄屏容器内滚动，读取失败有显式重试。
- 设置页展示已保存模型、密钥是否存在及本次测试状态；高级连接参数按需展开。密钥原值仍不回传。
- 页面首次访问才加载，访问过的表单/编辑器保留；两种制作工作流切换也保留简报。后台任务完成不再抢走当前页面。
- 所有打开草稿的入口共用未保存/处理中检查。修复作者 `#play` 刷新误进独立玩家页的问题；独立玩家入口继续使用 `#/play`。
- Agent 入口只准备请求。载入时保留已有输入，不自动发送；关联选中的已保存草稿/版本或原作。现有确认卡与业务执行边界保持生效。建筑、物品和模型设置的讨论入口不会新增相应写入工具。

## 实际验收

在本机开发服务和原有《武林外传：同福旧账》数据上检查，不调用付费模型、不创建生成任务、不发布新版本。

- 九个操作页在375×812、768×1024、1280×720渲染，检查页面/主内容宽度；发现并修正768px书架横向溢出。另目视检查真实世界草稿在手机上的画布、工具展开与检视器。
- 全局搜索实际命中原作、世界草稿和已完成制作任务。任务先过滤为“待审阅”得到空态，再重复搜索定位已完成任务，过滤复位且对应记录可见。
- Ctrl+K → 输入“模型设置” → 向下 → Enter，正确打开设置页。
- 世界页讨论请求带选中草稿ID与v4；当前输入非空时无法覆盖，清空后可载入并编辑，全程未发送。
- 未保存的新世界输入“界面检查临时输入”后，经搜索打开已有世界被拦住，原输入保留；随后通过界面放弃临时编辑。
- 临时制作简报在两种工作流和其他页面之间切换后保留，随后恢复样本；模型名临时输入跨页保留，随后从服务重新载入，未保存配置。
- 浏览器截图与日志放在被忽略的 `data/verification/workspace-ui/`；证据仅代表界面和交互验收，不宣称游戏平衡或生成质量达标。

## 边界

本轮没有新增 Agent 可调用的建筑/物品/模型设置写入模块；相应专业工具继续通过现有界面操作。页面输入仅在当前工作台会话的页面切换间保留，刷新页面仍可能丢失未保存的表单/编辑；已保存游戏、任务和对话仍由后端持久化。独立玩家界面和生成质量不属于本轮改版的重新验收范围。
