# 传统文字游戏编辑器用法精华（IF Editor Patterns）

> 目标：从 Twine / ChoiceScript / Ink / Inform 里抽出**作者与玩家怎么用**的模式，接到本书工坊（画布 + 数值 + 世界书），**不克隆**各自运行时。  
> 配套：`docs/stat-templates.md`（数值模板骨架）、`DESIGN_SYSTEM.md`（玩时 HUD / Stat Editor）。

---

## 1. 我们学什么、不学什么

### 取（精华）

| 来源 | 用法模式 | 对我们意味着什么 |
|---|---|---|
| **Twine** | 结构是**看得见的图**；画布是主编辑面；常从某节点试玩；变量是次要工具 | 无限画布继续当作者主舞台；试玩跟节点，不把图降成侧栏缩略图 |
| **ChoiceScript** | 数值是一等玩法：可随时查看的属性表；诗意展示名；选择先 **set**，后面再 **if**；代价写在数上；「Show Stats」节奏 | Stat Editor + 玩时常驻状态表；选项带代价提示；delta 用 displayLabel |
| **Ink** | 可见选项由状态筛出；重组优于爆炸式唯一节点；叙事脚本 ≠ 玩法改状态引擎 | `conditions` / 世界书门控筛选项；图可重组；AI 只叙述/提案，不直接突变 variables |
| **Inform（轻触）** | 硬世界模型与散文分离；规则引擎拥有状态 | 世界书 + 条件/效果拥有真相；散文/旁白只读状态 |

### 弃（糟粕 / 不学）

- **Twine**：大作靠临时 JS 堆状态 → 我们禁止 ad-hoc 运行时分叉，状态只走 `variables`。
- **Choice of Games 壳**：强制同一套读者壳 / 仅章节推进 → 我们保留工坊密度与图编辑，不做成 CoG 克隆。
- **Ink**：完全抛弃图 → 我们的作者受众需要看见拓扑，脚本味留给生成提示而非唯一作者面。
- **橙光系**：平台锁死当分发核心 → 不作为产品骨架。
- **Opposed-pair 运行时**：不新增引擎类型（日后展示层成对条可以，不进规则引擎）。

## 2. 映射到 book-to-game

| 模式 | 我们的表面 |
|---|---|
| 画布为主 | 无限画布（`BranchGraphCanvas`） |
| 数值一等 | `StatEditor` + `PlayStatsBar`（常驻，默认可折叠但不默认藏） |
| set → if 循环 | `effects` / `conditions` + 世界书 |
| 状态筛选项 | `choiceAvailable` / play overlay 灰显 |
| AI 不突变状态 | 既有融合规则：叙述/提案映射到已有 choice，规则引擎改变量 |

阅读节奏（玩家 / 画布试玩）：

1. 场景正文  
2. **状态表**（含选后 delta）  
3. 选项（带代价提示，不发明效果）  
4. 旁白 / 天道 / 自由输入 —— 更安静、靠后  

---

## 3. 玩时状态条启发式（ChoiceScript 灵感，自有 chrome）

- 有模板戳记时按 role 排序/分组展示：`resource` → `relationship` → `pressure` → `progress` → `flag`；未知 role 靠后。
- **数值**：旁注原始值；条宽启发式：
  - 值落在 **0…100**（含）→ 条宽 = 该百分比；
  - 否则条宽 = `clamp(0, abs(value), 100)` 的视觉封顶（无界属性只给相对手感，**不以条代替真相**；数字始终显示真值）。
- **旗帜**：开/关 pill，不用假进度条。
- Delta 行优先 `displayLabel`（模板可知时），否则裸变量名。
- 禁止紫色装饰；信号色沿用设计系统绿 / 中性线。

---

## 4. 作者侧

- **Stat Editor**：通用数值编辑器（模板灌初值 + 单局增删改）。
- **ChoiceRulesEditor**：条件 = 门控（gate），效果 = 代价/收益（cost）；逻辑不变，视觉与 Stat Editor 同属精密仪器语言。
- 不把 opposed-pair、骰子检定、题材专属 runner 写进引擎。

---

## 5. 成功标准（用法层）

玩家能回答：「我现在缺什么 / 压什么？选这个会掉什么？」  
作者能回答：「这张图的状态机在哪？哪条边在改数？」  
若只能「三选一翻页」，说明缺 effects 或 HUD 没露出 —— 回到选择题，而不是开放文字游戏。
