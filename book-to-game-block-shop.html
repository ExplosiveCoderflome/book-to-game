终局条件 · Agent 确认门 end-conditions

胜负条件决定整局成败。生成时 Agent 会基于游戏内容提出多套「胜利 + 失败」条件包（propose_end_conditions，只读）；作者挑一套或提交自定义文本，确认后才写入 world.endConditions（apply_end_conditions）。之后修改胜负条件属于重塑整局，必须显式确认严重度。详见 docs/end-conditions-agent-gate.md。
